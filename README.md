# Varanti

Smart Receipt & Warranty Tracker. Free, unlimited, no paywalls.

**Authoritative project guide:** [docs/MASTER.md](docs/MASTER.md)

| Layer | Stack |
| --- | --- |
| Mobile | Flutter (Android 10+ first; iOS later) |
| API | Python FastAPI |
| Data | Supabase (Auth, PostgreSQL + RLS, Storage) |
| OCR | Tesseract → Gemini Flash (hybrid) |

Start with [docs/SDLC.md](docs/SDLC.md). Human acceptance is required at each gate.

SRS source: `SRS-Varanti/Software Requirements Specification (SRS) - Varanti.pdf`.
