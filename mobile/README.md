# Varanti mobile (Flutter)

Android 10+ (API 29) first; iOS 15+ later per SRS.

This folder is a placeholder until a **GATE-6** plan is accepted. Do not generate a Flutter project until then unless you explicitly ask.

Planned responsibilities:

- Camera / gallery / compression (quality 65, max edge 1600px)
- Guest SQLite (no cloud)
- Auth via `supabase_flutter` (anon key + JWT)
- OCR confirmation modal
- Dashboard badges, search, settings
- FCM + share sheet for PDF
